# EXP-1/1.2 — Draft Manager (Frontend)

This experiment implements a frontend-only draft management system with CRUD operations and optional mock API simulation.

Quick start

```bash
cd EXP-1/1.2
npm install
npm run dev
```

Features
- Create, save, load, edit, and delete drafts
- Mock API simulating async backend calls and persisting drafts to `localStorage`
- Loading and saving states for improved UX
